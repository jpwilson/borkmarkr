bookmarker press kit

Last updated 2 September 2026

bookmarker is a bookmark manager for iPhone and web that solves the thing every social app gets wrong: saved posts that pile up with no titles, no search and no order. Save from any app's share sheet and it's filed into a topic automatically — fifty topics, over six hundred subtopics — and fully searchable by title, tag, note or the account it came from. Bulk import turns an existing pile of Instagram, TikTok, X or YouTube saves (or a browser bookmarks file) into a sorted library in one step. It syncs between iPhone and this web app, asks for zero permissions, and carries no ads, no tracking and no third-party SDKs. Built by a solo developer using AI coding agents; launched 2 September 2026.
