# Handles — claim order, bios, assets

No social accounts exist yet (confirmed open gap as of this writing). Claim
in this order on each platform — first one available wins, stop as soon as
one lands rather than holding out for a perfect match across all five
platforms:

1. `bookmarker`
2. `bookmarkerapp`
3. `bookmarker.lol`
4. `getbookmarker`
5. `bookmarker_app`

Check availability the same session you claim, on all five platforms at
once if possible — a handle that's free on TikTok this morning may not be
free this afternoon once posting starts and the name gets attention.

Note the vocabulary caveat from product memory: "bork" is planned for A/B
testing post-launch — don't etch it into a handle (e.g. `bork.mr`,
`getbork`) until that settles. Handles above all use the stable brand word,
**bookmarker**.

Link-in-bio target for every platform:
`https://bookmarker.lol/?utm_source=<platform>&utm_medium=bio&utm_campaign=link-in-bio`

## Asset reference

All brand art referenced above lives in `Marketing/brand/`:
- `clay-concepts/e_sockets_1.png` — the clay bookmark mark in active use;
  the correct avatar everywhere.
- `hero-bookmark.png` — bookmark + four platform tiles, no copy; best for

  ratio.
- `share-square.png` — 1080×1080, ready for Instagram grid/highlight use.
- Colours if any asset needs re-export: paper `#F6F3EE`, ink `#191510`,
  coral `#FF5A2D`, card background `#E6DBC6`. Type: Bricolage Grotesque 800
  (headlines), Instrument Sans (body). See `Marketing/brand/README.md` for
  the source HTML/regeneration commands.
