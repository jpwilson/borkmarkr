# Launch hooks — 5 families × 8

Short-form video hooks for the first month after launch (2026-09-02). Paired
1:1 with `scripts/` (one full script per family, for the first demo shoot of
each week) and `schedule.md` (which hooks run which day).

**Ground rules for every hook below:**
- Real screen recordings only. No mockups, no voiceover-only claims.
- App name is said once, at the close, never mid-hook.
- Import is **iPhone only today** — every import shot is recorded on an
  iPhone. Never show or imply a web importer; it's "coming to the web," not
  live. Never mention Pocket as a supported import *format* — the bridge is
  always "your browser bookmarks," which Pocket refugees already have.
- Never post to r/ADHD (it bans app posts). ADHD-adjacent hashtags are fine —
  reach that audience through the hashtag/creator layer, not the subreddit.
- Post captions never claim sharing/collections, never say "AI organizes
  everything," and privacy language matches the brief exactly.
- Every post/reply link uses `https://bookmarker.lol/?utm_source=<platform>&utm_medium=video&utm_campaign=<slug>`.
  Campaign slugs: scroll-of-shame (F1), export-mess (F2), recipe-in-march (F3),
  pocket-died (F4), ig-no-search (F5).
